集めていないもの

  • このサイトは Cookie を使いません。ブラウザへの保存（localStorage 等）も使いません。
  • アクセス解析・広告・外部の計測用スクリプトは入れていません。
  • 入力フォームはありません。

配信のために扱われるもの

このサイトは Cloudflare から配信しています。通信を届けるために、Cloudflare は IP アドレス・ブラウザの種類などのアクセスの情報を扱います。扱いは Cloudflare のプライバシーポリシーに従います。

外部のサイト

GitHub・Zenn・Misskey・VS Code Marketplace などへのリンクの先は、それぞれのサイトのプライバシーポリシーに従います。

お問い合わせ

GitHub の Issues から受け付けています。Issues に書いた内容は公開されるので、連絡先などの個人の情報は書かないでください。

変更

内容を変えたときは、このページを書き換えます。
