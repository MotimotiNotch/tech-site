できること

  • ひとりで最後まで持っていく

    設計・実装・公開・運用まで、ひとりで回します。下の5つは全部、配布か本番稼働まで出しています（Sirube と Warframe State Graph はリリース配布、loopfinder は VS Code Marketplace、CMS と Ruv は Cloudflare 上で稼働中）。

  • 推測で決めず、実物で確かめる

    「動くはず」で止めず、実際に動かして差を見ます。loopfinder は「フックあり／なし」の両側をテストで確かめ、CMS はデプロイの後に、拒否されるべきリクエストを実際に投げています。

  • 制約の中で設計する

    予算・API・権限が足りないことを前提に形を決めます。Ruv は無料枠の CPU 10ms に収まるよう処理を段に分け、Warframe State Graph は所持状態を取れる公式 API が無いので、自動同期をやめて1タップの入力にしました。

  • 人に分かる形にする

    作った仕組みを、他の人が読める文章に起こします。CMS の防御は Zenn の本に、Ruv の記憶の設計は記事にまとめています。
