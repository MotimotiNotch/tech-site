What I do

  • Carry things through on my own

    I handle design, implementation, release and operation by myself. Everything below has shipped or is running in production (Sirube, Sudare and Warframe State Graph as releases, loopfinder on the VS Code Marketplace, the CMS and Ruv live on Cloudflare).

  • Check against the real thing, not assumptions

    I don't stop at "it should work"; I run it and look at the difference. loopfinder's tests check both the with-hook and without-hook sides, and after each deploy of the CMS I actually send requests that should be rejected.

  • Design within constraints

    I shape things assuming budget, APIs or permissions will fall short. Ruv splits its processing into stages to fit the free plan's 10 ms CPU limit, and Warframe State Graph uses one-tap input instead of auto-sync because there's no official inventory API.

  • Make it understandable to others

    I write up what I build so other people can follow it. The CMS's defenses became a book on Zenn, and Ruv's memory design became articles (both in Japanese).
